# AHAQ Auto Exchange — Complete Website Expansion & Business System Plan

**Website:** https://www.ahhaqautoexchange.net/  
**Business:** AHAQ Auto Exchange  
**Market:** Jacksonville, Florida  
**Business model:** Automotive dealership + mechanic/auto repair + body shop + window tinting  
**Primary objective:** Turn the existing dealership website into a complete automotive business platform that generates vehicle sales leads, repair/body-shop bookings, service leads, estimates, customer accounts, and workshop operations.

> **Important location note:** The business is preparing to move to **6615 N Main St, Jacksonville, FL 32208**. Until the move is officially complete, the website should clearly distinguish the current/old location from the upcoming workshop location and use wording such as **“Moving Soon — New Workshop Location.”** The current public business record found during planning lists **8310 Beach Blvd Suite 2, Jacksonville, FL 32216** as the principal address. Confirm the operational/legal address before changing every location reference. The official website currently exposes a very minimal public page with the AHAQ Auto Exchange branding and a WhatsApp CTA, so the plan below treats the website as a foundation to expand rather than assuming existing features that were not visible in the crawl.
